# Créditos e componentes de terceiros

O VFL Voz Uniforme distribui, no pacote portátil publicado em **Releases**, componentes de terceiros com suas próprias licenças. O código e as marcas desses projetos pertencem aos respectivos autores.

## Audio Separator

Ferramenta utilizada para executar a separação de voz e acompanhamento.

- Projeto: https://github.com/nomadkaraoke/python-audio-separator
- Licença: MIT

## Ultimate Vocal Remover (UVR)

Tecnologia e ecossistema nos quais os modelos de separação utilizados são baseados.

- Projeto: https://github.com/Anjok07/ultimatevocalremovergui

## Modelo UVR-MDX-NET-Inst_HQ_3

Modelo MDX incluído no pacote portátil para separar as faixas **Vocals** e **Instrumental**.

## FFmpeg

Utilizado para ler, tratar, combinar e exportar áudio e vídeo.

- Site: https://ffmpeg.org/
- Licenças: https://ffmpeg.org/legal.html

## Python

O pacote portátil contém um runtime Python local para executar o separador de áudio.

- Site: https://www.python.org/
- Licença: https://docs.python.org/3/license.html

## ONNX Runtime e bibliotecas Python

O pacote portátil inclui ONNX Runtime e dependências necessárias ao Audio Separator. Os respectivos textos de licença acompanham a distribuição na pasta `third_party`.
